# Kaaos

Kaaos is a project developed directly after another one of the projects i contributed to: [Hanova](https://github.com/TheStarViper/hanova/)
Kaaos is a program made to solve the problem of developers not having files to use to test like media players, document viewers or just placeholder images that dont look garbage. Kaaos can generate random audio,image,document & video files along with other neat tools like audio visualizers!

> [!NOTE]
> The name "Kaaos" comes from the Finnish translation of "Chaos" which i felt was fitting for a random file generator.
